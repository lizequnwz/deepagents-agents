# Workbook contract

Always build and verify `advisor_matches.xlsx` in memory, with sheets in this
order:

1. `Matched`: one row per automated match with compact input/advisor identity,
   qualitative evidence, and decision provenance.
2. `Review Required`: one row per presented candidate, or one No Match row with
   no candidates. Blank highlighted `User Decision`, `Selected CRD`, and
   `Reviewer Notes` columns support offline review.
3. `Original Input`: source values in original column order with physical row
   numbers. All-rows firm overrides never alter this sheet.
4. `Run Summary`: purpose and edit boundary, confirmed mapping and fingerprint,
   input/status counts, source/reference hashes and provenance, policy version,
   generation time, and firm-resolution audit.

The default view is human-first. Freeze headers, add filters, style statuses,
wrap text, size columns to bounded content, and hide technical audit columns at
the right. Highlight the three user-editable review columns consistently.

Write every user-controlled value as text to prevent formula injection. Keep
CRD and ZIP as text. Reopen the generated bytes, verify exact sheet order,
reject formulas, and reconcile Matched plus unique Review Required items to
Original Input before returning the ZIP.

Row-level decisions appear only in the workbook. `result.json` contains summary
counts, warnings, mapping/source/reference/firm/policy metadata, and no row-level
decision payload. Downloaded workbooks are not re-ingested or revised.
